以下是在你的机器上配置并调试 VLA-openpi 的详细步骤：

### 第一步：基础系统准备

虽然项目依赖 `uv` 管理大部分库，但我们需要确保系统底层工具就绪。

1. 验证显卡驱动：
   确保你的 RTX 5090 驱动已正确安装。
   **Bash**

   ```

   ```

2. 安装系统依赖：
   我们需要 git、git-lfs（用于下载大模型权重）和 curl。
   **Bash**

   ```
   sudo apt update
   sudo apt install -y git git-lfs curl
   git lfs install
   ```

### 第二步：获取代码

该项目包含子模块（submodules），必须递归克隆。

**Bash**

```
# 如果你还没有克隆代码：
git clone --recurse-submodules git@github.com:Physical-Intelligence/openpi.git
cd openpi

# 如果你已经下载了代码（比如你上传的那些文件），请进入目录并确保子模块已更新：
git submodule update --init --recursive
```

### 第三步：安装环境管理工具 uv

该项目强制使用 modern 的 Python 包管理器 `uv`，它比 pip/conda 更快且能自动管理 Python 版本。

1. **安装 uv** ：
   **Bash**

```
   curl -LsSf https://astral.sh/uv/install.sh | sh
   source $HOME/.cargo/env
```

1. 配置 Python 环境：
   项目指定使用 Python 3.11（.python-version 文件中指定）。Ubuntu 24.04 默认可能是 3.12，但 uv 会自动下载并管理独立的 3.11 版本，不会污染你的系统。
   在 `openpi` 项目根目录下运行：
   **Bash**

   ```
   # GIT_LFS_SKIP_SMUDGE=1 是为了跳过拉取 LeRobot 的大文件，避免下载过慢
   GIT_LFS_SKIP_SMUDGE=1 uv sync

   # 以编辑模式安装当前项目，方便你修改调试代码
   GIT_LFS_SKIP_SMUDGE=1 uv pip install -e .
   ```

   *解释* ：这一步会自动安装 PyTorch 2.7.1、JAX 0.5.3 以及 CUDA 相关的 Python 库。**注意：** 项目文档明确指出，你不需要在系统层面安装 CUDA Toolkit（虽然你已经装了 12.8，这很好），`uv` 会在虚拟环境中处理 CUDA 依赖。

### 第四步：关键补丁 (Patching Transformers)

这是一个**至关重要**的步骤。根据 `README.md`，为了支持 Pi0 模型所需的特性（如 AdaRMS），必须手动给 `transformers` 库打补丁。

```
cp -r ./src/openpi/models_pytorch/transformers_replace/* .venv/lib/python3.11/site-packages/transformers/
```

 *警告* ：如果不执行此步骤，加载模型时会报错。

### 第五步：验证环境

我们来运行一个简单的 Python 脚本，验证 PyTorch 和 JAX 是否都能正确识别你的 RTX 5090。

### 常见问题排查 (Troubleshooting)

* UV Sync 失败：如果遇到网络问题，尝试设置 pip 镜像（uv 也支持）：
  export UV_PYPI_MIRROR=https://pypi.tuna.tsinghua.edu.cn/simple
* **Transformers 报错** ：如果你重新运行了 `uv sync`，它可能会覆盖掉你打的补丁。**每次 `uv sync` 后，建议重新运行第四步的 `cp` 命令。**
* **显存不足 (OOM)** ：虽然 5090 显存很大，但训练大模型时仍可能爆显存。
* 对于 JAX，可以在运行前设置：`export XLA_PYTHON_CLIENT_MEM_FRACTION=0.9`
* 对于 PyTorch，项目支持 `torch.compile`，推理速度应该很快。
