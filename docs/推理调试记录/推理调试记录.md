# 视频推理


既然你已经配置好了 `torch270cu128py311` 这个 Conda 环境，并且 `pip list` 显示核心依赖（如 `openpi`, `openpi-client`, `gym-aloha`, `mujoco`）都已经安装就绪，你可以**完全跳过** `uv` 和 Docker，直接用 `python` 命令来运行。

请确保你已经激活了该环境：

**Bash**

```
conda activate torch270cu128py311
```

然后按照以下步骤，在两个**独立**的终端窗口中运行命令：

### 第一步：启动策略服务器 (Terminal 1)

这个窗口负责加载模型并进行推理。为了防止 Hugging Face 连接超时，我们加上国内镜像的环境变量。

在项目根目录 (`VLA-openpi`) 下运行：

**Bash**

```
# 设置 HF 镜像并启动服务器
export HF_ENDPOINT=https://hf-mirror.com
python scripts/serve_policy.py --env ALOHA_SIM
```

* **成功标志** ：等待一段时间（下载权重可能需要几分钟），直到看到类似 `Server started` 或 `Uvicorn running on http://0.0.0.0:8000` 的日志。
* **保持开启** ：不要关闭这个窗口。

### 第二步：运行仿真器 (Terminal 2)

这个窗口负责运行物理仿真环境，并将观测数据发送给上面的服务器。

同样在项目根目录 (`VLA-openpi`) 下运行：

**Bash**

```
# 确保激活环境
conda activate torch270cu128py311

# 安装系统级渲染库 (如果之前没装过，这是 Ubuntu 运行 MuJoCo EGL 必需的)
# 只需要运行一次
sudo apt-get install -y libegl1-mesa-dev libgles2-mesa-dev

# 启动仿真
export MUJOCO_GL=egl
python examples/aloha_sim/main.py
```

* **注意** ：`MUJOCO_GL=egl` 是为了使用 EGL 后端进行渲染（即不弹窗，直接后台生成视频帧），这对服务器或远程环境非常重要。

### 第三步：获取视频结果

仿真程序运行大约 10-20 秒（或者完成一个回合）后，你可以按 `Ctrl+C` 停止它（如果不停止，它可能会一直循环跑）。

视频文件会自动生成在以下位置：

data/aloha_sim/videos/

你可以进入该目录查看：

**Bash**

```
ls -lh data/aloha_sim/videos/
```

你会看到类似 `out_0.mp4` 的文件。将它下载到本地播放，你就能看到机械臂在仿真环境中被你的模型控制着去抓取方块了！
